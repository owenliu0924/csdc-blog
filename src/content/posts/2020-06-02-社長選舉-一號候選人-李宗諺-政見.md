#

改變現今社團招生模式

將目前表單兩管道招生改為表單三管道招生，分別為面試、邏輯題目甄選及抽籤，目標分別為招收已具一定程度的新生、具有一定潛力的新生及對資訊有興趣但沒有先修的新生。由於軟研本身為獨立選社，因此可以此模式進行。

擴大招生宣傳，具體包括引用34th社長劉承軒學長的政見，包括但不限於製作宣傳單於跑班時宣傳，透過IG等管道加強宣傳力度。

#

修改目前教學模式

希望將社課模式加強為以社員主動學習為中心，會於前次上課在社網公佈下次上課的講義，上課僅做簡單檢討及再次說明講義中較難懂的部分並作補充，目標為於上學期結束C++基本語法，並留幾堂課讓學弟妹試上下學期分組課程。

延續社課學員分組制度，視情況決定每組人數，希望在社員遇到困難時能互助合作解決，並作為分組考的組別。

社課部分上學期維持僅一組C++基本語法，下學期則分為三組，包括進階C++(演算法)、網管(網安組，希望能教ctf等其他相關資安競賽類型)、Arduino、tensorflow或其他項目擇一。

鼓勵學員及幹部參加資訊相關培訓及比賽，包括但不限於資訊之芽、AIS3、TOI練習賽。

#

午休課程

作為竹中的資訊類學術社團，當仁不讓應負振興責任，因考慮有社員想提升程式競賽實力，所以，我想利用午休實施演算法課程，提升社員們的競賽實力。為此將於指定午休的時段開設課程，並製作相關講義。

如果tensorflow或其他課程無法成組的部分，考量會有社員想學習的需要，會徵詢有意願的社幹，在指定午休的時間來開放教學。

#

整治社團OJ(線上評測系統)及社網

針對每次課程出題，並依解決方法分類，重新審視題目難度，提高社內競賽頻率。由於加速社課，若社課中有空檔，視情況於課程時開小型競賽。

以社網、臉書及IG作為社團宣布事項正式管道，加強對外宣傳。

#

將講義分組分冊製作

編寫去蕪存菁的講義，並分冊分組由各組教學製作該組該學期要用的講義。

考慮講義線上化，可公布講義於社網。

#

加強與友社交流

本社自竹女資研(HGISC)創社以來即以該社及實驗資研(ICED)為主要友社，希望能撇除疫情因素，再啟聯合社課，並努力促成更好的迎新。

希望能與友社一同舉辦聯合競賽，讓社員走出竹中軟研。

拓展他校友社。

#

與校內友社合作

考量社員與社團分組狀況，視情況繼續與校內他社合作。

#

整理社窩書籍並製作借書單

社窩工具書眾多，希望能重新整理編列書單，建立完善的借還書機制，方便社員並方便管理。

將書籍依種類分類，並確實上鎖書櫃，製作借書單。
