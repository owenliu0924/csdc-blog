II.**變數型態**

1.基本輸出

前一章在介紹程式碼的基本架構時，我們以一段簡單的程式碼作為範例，如下：

#include\*

using namespace std;

main()

{

        cout<<”Hello CSDC!”<<endl;

        system(“pause”);

        return 0;

}

這 段程式碼中的「cout<<”Hello CSDC!”<<<」連接一串你想要輸出的文字或控制符號，什麼是控制符號呢？剛剛的endl其實是一個函數，他會輸出控制 符號「end line」，也就是換行的意思。這種東西稱為跳逸控制字元(escape sequence)，是使用在字串或字元中的控制符號，由反斜線「\」開頭。接著你看到包在” ”(雙括號)中的東西稱為字串，如果你只要輸出一個字元，則可以用’ ’(單括號)包起來。現在再來看看幾個範例吧：

cout<<”Hello CSDC!”<<endl;

cout<<”Hello CSDC!\n”;

//以上兩行相等

cout<<’Y’<<’a’<<’!’<<"\n";

//輸出Ya!並換行

以下是常見的跳逸控制字元：

\0 字串結束字元

\a 嗶一聲

\t 水平跳格

\v 垂直跳格

\n 換行字元

\? 問號字元

\\ 反斜線 字元

\’ 單引號字元

\” 雙引號字元

2.資料型態：

程式最重要的功能就是回應使用者，既然要回應，就要先輸入，程式才能依輸入的資料回覆使用者。

使用者想要輸入的資料類型有很多種可能，可能是數字或文字等，這些看起來差不多的資料，在程式中可是大有學問喔，在介紹程式輸入前，我們就先來介紹一下「資料型態」吧！

以下列出常見的資料型態：

資料型態中文佔記憶體空間可用數值範圍

int

整數

4 Bytes

-2147483648~+2147483647

float

浮點數

4 Bytes

3.4×10^(±38)

double

雙倍精浮點數

8 Bytes

1.7×10^(±308)

char

字元

1 Bytes

-128~+127

※以上數據根據編譯器、硬體有所不同

int是整數(integer)，如果你把小數的資料丟進去他會自動去掉小數部分。

float是浮點數，如果你想要使用到數值較小但有包含小數點的話，可以考慮使用它。小數在記憶體儲存的方式是利用科學記號來儲存，由於佔用記憶體大小有限，float只能精確到小數點後第7位，而double卻可以到12位。

char是ANSI(美國國家標準委員會)定義的256種字元，包括英文字母、數字、標點符號等。

大概了解資料型態後，請你看以下範例：

#include\*

using namespace std;

main()

{

        int x;

        cin>>x;

        cout<<

        system(“pause”);

        return 0;

}

現在要說明的是加粗的程式碼，而其他部分在之前就已詳細介紹過了。

第一行的「int x;」如果以中文表達，意思是「宣告一個整數變數，叫做x」，看完中文翻譯後，有沒有想法啊？沒關係，這裡跟各位說明一下變數在程式中的重大意義：程式執行時，常常需要讀取、寫入資料，這時就需要變數來幫忙了。宣告的意義在於配置記憶體空間給它，所以想要讀寫一個變數，必須要先宣告它。宣告的語句中必須要有它的資料型態和你想要給它的名稱，就像範例中的「int x;」。程式中也可以使用逗號「,」來一次宣告多個變數，如「int x,y,z;」，但變數的命名有一些限制：

長度不可超過255個字元。
由數字、英文字母、「$」或「\_」組成。  
第一個字不可用數字。  
不可使用保留字或關鍵字(程式特定語句，像是if、else、break、int等等)

在宣告變數時也可以給定一個初始值，例如「int x=0;」。

3.基本輸入

了解怎麼宣告變數後，你就可以開始學「基本輸入」了。先介紹一個語法：

cin>>變數名;

它 是cout的兄弟，cout用來輸出，另一個當然是用來輸入囉。要小心的是它們的箭頭方像不一樣。當程式執行到cin時，會等待使用者輸入資料後按下 Enter，資料就會存入變數中再繼續執行，這時程式就可以使用你輸入的資料了。cin也可以使用「>>」來讀取多筆資料，例如 「cin>>x>>y>>z;」。來看個範例吧：

#include\*

using namespace std;

main()

{

        int num1,num2;

       cout<<”請輸入num1：”<

       cin>>num1;

       cout<<”請輸入num2：”<

      cin>>num2;

      cout<<”num1的值為”<<

      cout<<”num2的值為”<<

      system(“pause”);

      return 0;

}
