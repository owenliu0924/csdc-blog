I.基本架構

你在前一章已經初步了解程式語言的發展及類型，在這一章我們要正式進入C++程式設計的領域了。

1.編譯器

我們要使用的編譯器是「gcc」，而使用的整合開發環(IDE)是「Dev C++」，它是一個免費的軟體，在網路上搜尋「Dev C++」就可以下載安裝。

2.程式碼的基本架構

在學習程式碼的基本架構前，你要先知道，在程式碼中，「//」之後一行內的文字為註解，電腦不會執行它，而在「/_」之後「_/」之前的文字也是註解喔！

請看下列程式碼：

#include\*

using namespace std;

main()

{

        cout<<”Hello CSDC!”<<endl;

        system(“pause”);

        return 0;

}

看起來都是一堆英文字母和一些符號，但其實沒有想像中那麼難，現在就來分析它們的意義。

首先你要知道，在程式中，任何輸入、輸出都要先寫好可以從鍵盤輸入並從螢幕輸出的「方法」，而有些像這種常用的基本「方法」在C++中的「標準函式庫」已經幫你寫好了，「標準函式庫」他非常龐大，是由許多標頭檔組合而成。

至於什麼是標頭檔呢？你可以說，這是已經寫好了各種解決問題「方法」的程式碼的檔案，而這些程式碼都是我們常用的工具。有了這些標頭檔，可以讓你寫程式更為輕鬆，甚至在未來你有一定的能力時，你可以自己寫一個標頭檔，把C++沒有提供的，但常用的東西寫進去。如上面的cout這個控制輸出的物件，就是定義在iostream這個標頭檔中。

而當你想要使用這些「方法」時，你可以直接用include這個前置指令來引入標頭檔：

#include<標頭檔名稱>

#include”標頭檔路徑”

其實，標頭檔就是含有程式碼的文字檔，也是需要經過編譯的。而上面兩行都是用來引用標頭檔的方式，差別就在於你的使用時機，上面的是用來引入C++提供之標準的標頭檔，而下面的則是用來引用自己或識別人撰寫的標頭檔。

要使用標準函式庫裡的功能，除了要先引用之外，還要「開啟」它。標準函式庫撰寫在std(standard 標準)這個namespace(名稱空間;命名空間)中，想要開啟它就要使用以下指令，也就是一開始你看到的程式碼中的第二行：

using namespace std;

你要特別注意的是，在C++的程式碼中，除了前置指令(如#include\*)之外，指令的每一行結束都要加上分號「;」。

接下來，main(){ }是主函數，執行程式時，電腦會從這裡開始執行。每個程式都有main(){ }主函數，而且只能有一個，另外，main後面的小括號不可省略。而執行的敘述要放在大括號裡頭。

再來我們看到最後兩行：

system(“pause”);

return 0;

「system(“pause”);」是在Windows環境中用來讓程式暫停的指令，(在Linux的環境中不可加上「system(“pause”);」)。而「return 0;」表示程式結束。

最後說明一個最重要的重點：程式執行時是由上而下讀取程式碼來執行循序執行。這一點現在看起來很直覺，但當你有一天想要擴充你曾經寫好的程式的功能時，千萬要記得這個原則，不可亂插入程式碼！
