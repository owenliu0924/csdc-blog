基礎C++程式碼：

"Hello, world!"

---------------此線以下為程式碼-------------------

#include<iostream>

using namespace std;

main()

{

int a=0;

int b=0;

cin>>a;

b=a;

cout<<b;

cout<<"hello, world!";

system("pause");

return 0;

}

補充:

int是宣告一個整數變數

float是宣告一個浮點數變數

double是宣告一個倍精度浮點數變數

long long int 是宣告一個長長整數變數

unsigned int 是宣告一個正數整數變數
